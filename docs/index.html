快速开始

三分钟跑起来

安装
# 需要 Node.js ≥ 18
git clone https://github.com/huntina6/ttkj.git && cd ttkj
npm install
单次出图（匿名可用，无需任何账号）
node cli.js --oid 404135596 --once
绘制指定评论（旧置顶等）
node cli.js --oid 404135596 --rpid 313406396048 --once
生成 UP 互动回顾图（自动识别 UP）
node cli.js --oid 404135596 --rpid 313406396048 --context --once
持续监控（需 B站 Cookie）
node cli.js --uid 401315430 --cookie "SESSDATA=xxx; bili_jct=yyy" --watch -i 60
主要参数
参数说明
--oid动态 ID 或链接（含其置顶评论）
--rpid评论 ID 或链接，直接绘制该评论卡片
--context与 --rpid 联用，生成 UP 互动回顾图
--uid目标 UP 主（配合 Cookie 自动识别置顶动态）
--cookie登录 Cookie（可选）：完整子回复 + 降低风控
--watch / --once持续监控 / 单次检查
--track-dyn同时监测普通动态更新
